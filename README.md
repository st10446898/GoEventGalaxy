# GoEvent Galaxy – Android Event Booking App

## About the Project

GoEvent Galaxy is a native Android event discovery and booking application developed using Kotlin and Android Studio.

The application allows users to discover events, explore activities, save their favourite events, book tickets and manage their profiles. It aims to make finding and attending events easier through a modern, user-friendly mobile experience.

## Features

- **User Authentication:** Register, log in and manage user accounts.
- **Home Screen:** View event highlights and personalised information.
- **Explore Events:** Browse and discover available events.
- **Event Details:** View information about individual events.
- **Ticket Booking:** Book tickets for events.
- **My Tickets:** View and manage booked tickets.
- **Saved Events:** Save favourite events for later.
- **GoPoints:** Earn and track reward points.
- **Achievements:** View achievements and progress.
- **User Profile:** Manage personal account information.
- **Notifications:** Receive relevant application updates.
- **Map Integration:** Explore event locations.
- **Dark and Light Mode:** Switch between different appearance settings.

## Design

GoEvent Galaxy uses a purple and lavender galaxy-inspired design.

The application includes two themes:

- **Deep Space:** Dark theme.
- **Cosmic Dawn:** Light theme.

The interface is designed to provide a clean, modern and easy-to-use experience.

## Architecture

The application follows the MVVM (Model-View-ViewModel) architecture with a Repository pattern.

This helps separate the user interface, application logic and data management, making the project easier to maintain and develop.

## Installation

1. Clone this repository:

   `git clone https://github.com/st10446898/GoEventGalaxy.git`

2. Open Android Studio.
3. Select **Open** and choose the cloned project folder.
4. Allow Gradle to synchronise.
5. Configure the required Supabase project credentials locally.
6. Connect an Android device or start an emulator.
7. Click **Run** to launch the application.

## Configuration

GoEvent Galaxy uses Supabase for backend functionality.

To run the application, configure the required Supabase URL and publishable/anonymous client key using the project's local configuration.

Never upload private service-role keys, passwords or other sensitive credentials to GitHub.
